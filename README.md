# Mini Tools

Un ensemble de trois petits outils évolutifs :

## 1. Tier List
Fichier : `tierlist.py`  
Gestion simple d'une tier list.

## 2. Balance Pour/Contre
Fichier : `balance.py`  
Outil permettant de lister des arguments pour et contre.

## 3. Roue Aléatoire
Fichier : `roue.py`  
Sélection aléatoire parmi une liste d'options.

## Objectif
Projet léger et modulable permettant d'expérimenter et d'améliorer progressivement plusieurs petits outils.
